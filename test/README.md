# Flutter tests

- `unit/`: future tests for models, ViewModels, helpers, and services using injected fakes.
- `widget/`: future tests for screen/component rendering, user actions, and loading, empty, data, and error states.

These folders reserve space only; no tests or passing results are claimed. Add tests alongside app implementation after the Flutter project and its dependencies are initialized. Android end-to-end scenarios use ARTEMIS and are documented separately in `../e2e_test/`.
