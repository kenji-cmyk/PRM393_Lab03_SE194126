# Application assets

Store the Lab 2 design's runtime images in `images/`, icons in `icons/`, and licensed font files in `fonts/`. Add only assets actually used by the app and declare them in `pubspec.yaml` when the Flutter project is initialized.

App screenshots, Firebase console captures, and test/review output belong in `../evidence/`; they are not runtime assets. The reference PDFs in `../docs/requirements/` stay local and are not app assets.
