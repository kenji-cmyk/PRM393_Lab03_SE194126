# PRM393 Lab 3 — Cloud-Enabled Mobile App

Flutter and Firebase lab project scaffold with an MVVM app layout, ARTEMIS pytest suite, Firebase configuration, documentation, evidence, report, and slides.

## Repository layout

- `lib/` — Flutter app code organized into data, domain, and presentation layers.
- `e2e_test/` — ARTEMIS pytest suite and shared fixtures.
- `android/` — Android project configuration. Add the Firebase-generated `google-services.json` for your Firebase project here.
- `firebase/` — Firebase Storage rules and Remote Config defaults.
- `docs/` — architecture, traceability, analytics, test plan, and code review documentation.
- `evidence/` — console, DebugView, Crashlytics, ARTEMIS traces, and screenshots.
- `report/` — final `Lab03_<StudentID>.pdf` report.
- `slides/` — final `Lab03_<StudentID>_slides.pdf` presentation.

Add assignment reference PDFs under `docs/requirement/` when needed.
